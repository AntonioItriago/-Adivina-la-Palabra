# 🇻🇪 Adivina la Palabra — Telegram Mini App

Adaptación tipo *Wordle* con modismos, regionalismos y léxico de la cultura venezolana.  
Desarrollada como **Telegram Mini App** con monetización mediante anuncios (Monetag).

## ✨ Características
- 🎯 6 intentos para adivinar una palabra de 5 letras
- 🎨 Teclado dinámico con código de colores (verde / amarillo / gris)
- 💡 Pista gratis mediante anuncio bonificado (Rewarded Video)
- 📢 Anuncios interstitials cada 3 partidas
- 📱 Vibración háptica y adaptación al tema de Telegram
- 🇻🇪 Diccionario con palabras como `AREPA`, `CHAMO`, `PANAS`, `CORO`...
